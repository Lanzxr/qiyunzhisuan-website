> 最后核对：2026-08-15

## 会话启动

1. 读取本文件和 [MODULE_INDEX.md](./MODULE_INDEX.md)。
2. 选择最小模块集合。
3. 读取目标模块 README 和最新维护条目。
4. 只有跨模块或共享 seam、安全、存储、运行面、发布任务才读取 [TECHNICAL_PLAN.md](./TECHNICAL_PLAN.md)。
5. 检查 Git 状态并保护并行修改。

## 文档事务

- Interface、逻辑、数据、错误或所有权变化：更新模块 README。
- 每个修改任务：更新模块日志和全局台账。
- 路由变化：更新模块索引。
- 跨模块 seam 变化：更新全局技术规划。

所有未确认占位项必须在首次实现任务前核实，或改写为带原因的明确未知。
